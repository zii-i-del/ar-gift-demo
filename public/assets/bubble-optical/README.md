# 粉蓝参考材质 v1.4.1

以参考九宫格左上角为目标：青蓝上沿、亮粉右侧、蜜桃中央、淡紫下部，保留两块白色灯箱反光。颜色由 Blender 可编辑节点制作，灯箱反光由 Cycles 单独渲染；这不是从参考图裁切提取的成品。

source/bubble-matcap-v1.4.blend 保存两种材质。默认球面是彩膜材质；切换到 Separate_White_Softbox_Reflection 可检查独立高光。source/build_matcap.py 再生成两张 512×512 MatCap。球面形变 GLB 沿用前版，破裂控制器在 runtime/optical-bubble.js。

实时按正面球面法线采样颜色和反光，颜色层小幅流动、高光稳定。三次采样：膜面、高光、共享背景，比前版少一次。基础膜面权重 0.78，外沿最高 0.93；这是线性颜色混合权重，不是物理透射率。出生淡入保留 .10 秒，移除 stream 固定 0.55 全局淡化。默认可透过少量背景，外观优先于真实光学。

主项目同步 lib/bubble-optics.js、lib/bubble-renderer.ts 和 public/assets/bubble-optical 下贴图。保留当前 96 槽位、5 秒生命周期和互动；中心破裂 .06 秒，液滴 .32 秒结束。旧预览 http://127.0.0.1:8763/preview/?v=1.4.0 也显示本版，方便现有窗口刷新。新包可单独启动静态服务，访问 preview/。

验证：主项目构建通过。独立预览 1/10/20 颗和 30 轮破裂资源检查通过，主渲染器 96 个状态槽位、测试视频、破裂结束和空池跳过检查通过。均为 Chromium SwiftShader 功能检查，不是真机帧率结论。新两张图的体积和显存高于旧小 LUT，未宣称整体性能提升；绘制次数未增加。

限制：颜色和灯光是艺术化预设，不能响应真实房间光照；共享背景不包括其他泡泡，因此重叠区仍可能覆盖后方泡泡的膜面。浓色版本这一限制更容易察觉。独立 preview 的最大展示数量仍为 20；主项目池为 96。尚未进行真人摄像头验收，也没有线上发布。

## v1.4.1 色带弧度调整
顶部青蓝与下方粉色、底部蓝紫均采用带轻微偏斜的弧形色场，扩大衔接宽度。只重新生成膜面贴图；高光、运行时着色器和互动逻辑不变，不增加实时计算。
