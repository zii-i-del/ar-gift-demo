# 当前泡泡素材：粉蓝材质 v1.4.1

直播由 `lib/bubble-renderer.ts` 加载以下文件：

- `bubble.glb`：球面及形变。
- `film-matcap.png`：粉蓝彩膜。
- `highlight-matcap.png`：白色灯箱高光。
- `studio-environment.png`：破裂液滴环境贴图。

材质和破裂由 `lib/bubble-optics.js` 控制。泡泡池为 32 个，寿命 5 秒；膜面退场 0.06 秒，液滴 0.32 秒结束。容量以代码为准。

材质沿用既有 v1.4.1 色带，膜面权重 0.78、高光强度 1.4。颜色和灯光为预设，折射背景仅采样摄像头，不包含其他礼物。此次清理没有修改当前模型或贴图字节。

已移除未使用的旧 LUT 和膜厚贴图。回归测试验证模拟及材质输入；真人观感和设备性能需单独验收。
