# 泡泡素材 · 粉蓝材质

泡泡渲染器加载以下文件：

- `bubble.glb`：球面及形变
- `film-matcap.png`：粉蓝彩膜
- `highlight-matcap.png`：白色灯箱高光
- `studio-environment.png`：破裂液滴环境贴图

材质和破裂效果由 `lib/bubble-optics.js` 控制。泡泡池容量为 32 个，寿命为 5 秒；膜面退场持续 0.06 秒，液滴在 0.32 秒结束。运行参数以代码为准

粉蓝色带的膜面权重为 0.78，高光强度为 1.4。颜色与灯光采用预设，折射背景采样摄像头画面，不包含其他礼物。这是一种面向视觉表现的光学近似

观感和性能应结合实际设备、浏览器与摄像头画面验证
