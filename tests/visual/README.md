# 独立视觉测试

运行 `pnpm test:visual`，打开 http://127.0.0.1:3002/ 。

- `?view=composition`：160 星星、12 爱心、32 泡泡的合成检查。
- `?view=stars`：星星材质与翻转。
- `?view=hearts`：爱心运动对比，含碰撞和退场。

只挂载当前选择的测试，切换链接会卸载旧页面。工具直接使用当前 lib 代码及 public 模型，不复制渲染实现；测试视频放在本目录。

`pnpm test:visual:build` 检查工具编译，产物忽略且不部署。视觉工具通过开发服务使用，正式构建不包含这些页面、入口或视频。旧预览地址已删除，不提供兼容跳转。
