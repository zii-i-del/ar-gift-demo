## 如何运行

在项目根目录使用 Node 22.13 以上版本（本次实际验证版本见上）：

| 命令 | 内容 |
| --- | --- |
| `npm test` | 当前可通过的回归脚本；逐项输出结果，任何失败均以非零状态退出 |
| `npm run test:baseline` | 横竖屏的固定发射时间、尺寸、坐标、运动与接触轨迹 |
| `npm run test:perf` | 现有彩带及头部碰撞 CPU 隔离基准，不是整机帧率 |

测试代码由 Node 单独执行，不由业务页面导入。测试输入也不放在 `public/`，不会随摄像头或直播页面运行。
