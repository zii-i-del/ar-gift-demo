# 自动彩带触发与发区修正验证（2026-09-12）

## 变更

- 调度允许分割跨越基础任务目标频率，但估计时预留后续脸、手推理和每次 34 ms 采帧等待，仍限制结果年龄为手 200 ms、脸 250 ms。预算仍为每秒 700 ms、桶容量 700 ms；估计耗时附加 15% 余量。
- 准备期优先两次头发结果；实际内部发区连续稳定才启动。连续两次有效结果均无内部候选时允许仅外轮廓/肩部承接，不将失败当无内部头发。
- 一次短暂模糊结果暂停累计，明确离开立即取消；身份变化、过期重新确认。准备超时不消耗重新布防资格；有效新确认后允许重试，旧请求不会补播。
- 头发结果到达即评估启动；横屏含边取景与竖屏裁剪使用同一坐标映射。大小、数量、粒子停留、模型配置未改。
- 调试显示准备状态、中断原因、调度原因、最近一秒任务次数、结果年龄、承接计数及采帧状态。

## 浏览器短时检查

本地内置浏览器、横屏、实际摄像头、手动触发：一轮共 36 次头发识别、32 次身体识别，准备状态到达 interior，结束后活跃粒子归零。读取到的 P95 为 17.4–17.5 ms，未降档。第一帧头发推理约 124.4 ms，后续最后一次为 34.2 ms；冷启动波动需继续关注。

手动触发绕过捂嘴与准备门槛，以上不能证明真人捂嘴成功率、首批落点或完整性能通过。

切换/开发热更新后的竖屏检查出现采帧停滞：Worker 非忙碌，视频 currentTime 与 lastVideo 均为 0，只有第一条手部结果；保护状态正确阻止新发射。没有通过重复推理同一帧来掩盖问题。继续完整刷新验证，不能将渲染 P95 正常视为识别恢复。
