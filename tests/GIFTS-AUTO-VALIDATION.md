日期：2026-09-12。范围：本地原型；未部署、未接入真实推流。

## 实现入口

- `/`：自动手势模式，三张静态动作介绍；横屏 16:9 / 竖屏 9:16。
- `/?debug=1`：实时任务采集时间、年龄、平均执行频率、CPU 提交时间、异步 GPU 时间、资源计数、降档与保护次数。手动彩带仅为调试，不验证捂嘴准确率。
- `/gift-composition`：固定测试视频，160 星星、12 爱心、32 泡泡，单 WebGL 上下文；不含识别模型。
- `/legacy`：原单选回归入口，不与自动入口同时初始化。

## 实测片段（不是持续运行验收）

Codex 内置浏览器、开发模式，未记录硬件型号和浏览器版本；不能列入正式支持设备清单。

1. 竖屏等待片段：P50 约 16.7 ms、P95 17.5 ms，未降档；GPU 单次采样约 0.10 ms；此时没有活跃礼物，不能代表叠加成本。
2. 彩带调试轮次后：任务累计出现头发 16 次、身体 2 次。证明按需任务启用，不代表达到了配置频率上限。
3. 同时保留合成压力页的横屏片段：P50 33.3 ms、P95 34.0 ms，触发低档和保护；脸手当时平均约 8.9 Hz。该片段超过 33.3 ms 红线，记为性能未通过。并行压力页及开发环境可能影响结果，需隔离复测，不能归因为单一模块。

4. 停止并行合成压力页并恢复互动后：P50 16.7 ms、P95 17.3 ms；保护自动解除，仍保留低档；脸手结果恢复更新，未自动升档，浏览器无错误日志。仅为恢复行为验证。
