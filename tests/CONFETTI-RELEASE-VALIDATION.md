# 彩带连续触发修复验证（2026-09-12）

## 实现

- `mouth-region.ts` 共用同一组六个手指/掌部点、映射及嘴部参考进行覆盖/离开/未知分类。区域与口部安全范围明确分离才记为离开；仅方向不对不等于释放。
- 稳定手 ID 携带其原始关键点引用，避免识别数组重排或过滤后错配；不复制整份关键点。
- 释放需要同手至少两次有效结果和100ms有效累计。未知/丢失暂停累计，不计入时间；最后有效离开结果超过200ms则重新确认。身份间不共享累计。
- 已完成释放由协调器保留，播放中也可完成；不依赖爱心/泡泡事件。
- 调试 JSON `mouthRelease` 显示每手分类、有效累计毫秒和中断原因。
- 模型、频率、对象池、横竖屏数量尺寸和渲染未修改。

## 自动检查

通过 mouth-release、gift-coordinator、confetti、confetti-config、confetti-worker、gift-scheduler-regression、gifts-auto、primary-emitter、hand-tracks。

协调器测试包含：每个方向20轮身份丢失/恢复；每个方向5轮自然离嘴关键点经真实 readHand 解析后的连续播放（无其他礼物动作）；旧指尖距离规则拒绝相同输入；未知暂停；异步脸手结果；重复时间戳；身份切换；突然出屏；持续捂嘴；准备超时；尺寸数量回归。

这些输入是合成关键点，并非真人准确率测试。
